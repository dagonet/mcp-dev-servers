# `template_migrate_manifest` — the v2 → v3 migration contract

**This document moved.** It lives in `claude-code-toolkit` as
`docs/template-sync-migration-contract.md` from that project's **v4.0.0**, alongside the
server it describes, which now ships from that repo's `server/` directory.

It is kept here as a pointer rather than deleted because this repository's CHANGELOG links to
it from the 0.3.5 and 0.3.6 entries, and those entries are the record of how the contract was
written and corrected. A dead link would make that history harder to follow, which is the
opposite of what the document was for.

The last release of this package that shipped the server itself is **0.3.9**; `template-sync`
was removed in **0.4.0**.
